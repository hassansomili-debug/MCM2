# نضج MCM

واجهة MVP لمنصة قياس النضج الاتصالي التسويقي، مبنية كواجهة ثابتة قابلة للفتح مباشرة.

## التشغيل

افتح `index.html` في المتصفح. لا توجد حاجة إلى تثبيت حزم أو تشغيل خادم في هذه النسخة.

## نطاق النسخة الحالية

- لوحة تنفيذية عربية RTL.
- درجة MCM الكلية ومستوى النضج.
- الأبعاد السبعة مع درجاتها والفجوات ذات الأولوية.
- SMCE كقياس مستقل عن MCM.
- مسار زمني للدرجة وخارطة أولويات أولية.
- تنقل أولي بين مساحة الشركة ومساحة الباحث.

## الخطوة الإنتاجية التالية

ربط الواجهة بخدمة FastAPI وقاعدة PostgreSQL لإدارة نسخ أداة القياس، الإجابات، محرك الدرجات، التوصيات، الموافقات، والتصدير البحثي Excel/SPSS/PDF كما هو موصوف في وثيقة المتطلبات.
