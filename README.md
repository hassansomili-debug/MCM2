# مقياس النضج الاتصالي التسويقي

منصة عربية RTL للمنشآت الصغيرة والمتوسطة، تربط النضج الاتصالي التسويقي (MCM) بالكفاءة الاتصالية عبر وسائل التواصل الاجتماعي (SMCE) ضمن نموذج تشخيصي أولي واضح الحدود.

## التشغيل المحلي

لا توجد حزم خارجية مطلوبة؛ يكفي Python 3.9 أو أحدث:

```bash
cp .env.example .env
python3 server.py
```

ثم افتح `http://127.0.0.1:8000/`.

اضبط حساب مدير المنصة محليًا في ملف `.env` غير المتعقب:

```dotenv
MCM_ADMIN_NAME=مدير المنصة
MCM_ADMIN_EMAIL=your-admin@example.com
MCM_ADMIN_PASSWORD=replace-with-a-private-secret
```

لا يوجد حساب عرض تجريبي، ولا تُعرض أي كلمة مرور في الواجهة أو المستودع.

## ما تم تنفيذه

- تسجيل، دخول، خروج، استعادة كلمة المرور، جلسات آمنة، مؤسسات متعددة، تبديل المؤسسة وRBAC للأدوار الخمسة.
- صفحة تسويقية عامة، دخول مباشر للمشارك بلا حساب، وتسعة متغيرات سياقية تشمل عدد الموظفين ونموذج الأعمال وحجم فريق التواصل وحالة التنظيم الرقابي، إضافة إلى دور المجيب.
- أداة الإصدار العلمي v0.2 كاملة: 67 بندًا ثنائي اللغة (12 ممكنًا، 28 MCM، 15 SMCE، و12 نتيجة اختيارية) داخل إصدار المنصة `0.4.0`.
- مقياس «مدى الانطباق» اللفظي، ومقياس مستقل لمقارنة أداء الأعمال بالمنافسين، مع `NOT_APPLICABLE` و`DONT_KNOW` دون إدخالهما في الدرجة.
- أداة علمية بإصدارات غير قابلة للتعديل بعد النشر، معاينة واستيراد DOCX، مراجعة، اعتماد Pilot، نسخ وأرشفة.
- تقييم كامل مع autosave، حفظ واستكمال، مراجعة النواقص، تسليم مقفل، وإعادة تقييم.
- محرك تصحيح حتمي على الخادم: تطبيع 0–100، reverse coding، أوزان، missing data، ودرجات منفصلة لـMCM وSMCE مع قراءة فجوة العلاقة المقترحة دون ادعاء سببي.
- تصنيف المنشأة ضمن خمس مراحل: تفاعلي، مستجيب، مُدار ومتكامل، استباقي ومتكيّف، مؤسسي وذكي.
- سجل score runs غير قابل للاستبدال، تشخيصات، فجوات إلى المرحلة التالية، أولويات، توصيات وخارطة 30/90/180 يومًا.
- داشبورد نتيجة للمشارك: رادار MCM، مؤشرات SMCE والممكنات والنتائج، نقاط القوة وفرص التحسين، مصفوفة الأثر/الجهد، وخارطة التنفيذ.
- طبقة اختيارية لخطط التحسين عبر Groq أو Gemini أو Ollama، مع إزالة المعرّفات ومسار حتمي محلي عند التعطيل أو فشل المزود؛ الذكاء الاصطناعي لا يغير الدرجة أو التصنيف.
- لوحة ونتائج وتاريخ وقياس مرجعي محمي بحد أدنى للعينة.
- تقارير PDF مرئية برسوم الأبعاد والمراحل، Excel من 10 أوراق، وحزمة SPSS تشمل XLSX وCSV وcodebook وvalue labels وsyntax.
- وحدة بحث مجهّلة، جودة بيانات، إحصاءات وصفية، سجل تدقيق، إشعارات، إعدادات ولوحة إدارة.
- واجهة SPA عربية متجاوبة مع مسارات hash وحماية مسارات حسب الدور وحالات تحميل/فراغ/خطأ.

## الاختبارات

```bash
python3 -m unittest discover -s tests -v
```

تغطي الاختبارات الدخول المباشر، حفظ الديموغرافيا، حساب العلاقة والتصنيف الخماسي، الحفظ والاستكمال، PDF، Excel/SPSS، العزل بين المؤسسات، RBAC، منع تسريب الملفات، ورفض ملف المواصفات بوصفه بنك أسئلة.

## الحالة العلمية

النسخة المزروعة للمنصة `0.4.0` مصدرها الأداة العلمية `0.2` وحالتها العلمية **EXPERT_REVIEW / PROVISIONAL_NOT_VALIDATED**. تُنشر تشغيليًا بصفة **PILOT** فقط، وتظل العلاقة MCM → SMCE وحدود التصنيف الخماسي مؤقتة إلى أن يكتمل الاختبار الاستطلاعي والتحقق الكمي. لا تُعرض صفة `VALIDATED` تلقائيًا.

## خطط التحسين والذكاء الاصطناعي

الوضع الافتراضي `MCM_AI_PROVIDER=off` ويولد خطة محلية قابلة للتدقيق. للتجربة السحابية المجانية اضبط `groq` أو `gemini` وأضف المفتاح كسر في الخادم، أو استخدم `ollama` على خادم خاص. لا ترسل المنصة للمزود أسماء المنشآت أو البريد أو الإجابات الخام؛ ترسل درجات أبعاد مجمعة وفئات سياقية عامة فقط.

## التخزين والنشر

التشغيل الحالي يستخدم SQLite ومسار القاعدة يضبط عبر `MCM_DB_PATH`. هذا مناسب للتطوير، ولخادم دائم بقرص/volume ثابت، لكنه **غير مناسب لملف `/tmp` على Vercel** لأن البيانات هناك مؤقتة. يحظر فحص الصحة النشر الصامت بإظهار `sqlite-ephemeral-warning` على Vercel.

لإطلاق إنتاجي دائم استخدم خادم Python دائمًا مع volume مشفّر الآن، أو نفّذ محول PostgreSQL وفق `migrations/001_postgresql.sql` قبل توجيه بيانات حقيقية. راجع `docs/deployment.md` و`docs/security.md`.
