# نضج MCM

واجهة نضج MCM مع أول طبقة تشغيلية لخدمة API وتخزين SQLite.

## التشغيل

شغّل `python3 server.py` ثم افتح `http://127.0.0.1:8000/`.

حساب التطوير الأولي: `sara@example.com` / `ChangeMe-2026`. يجب تغيير كلمة المرور قبل أي نشر.

## نطاق النسخة الحالية

- لوحة تنفيذية عربية RTL تُحمّل درجاتها من API.
- تسجيل دخول بجلسة Bearer، مؤسسة، عضوية، ودور مدير.
- أبعاد MCM السبعة وSMCE الخمسة محفوظة في قاعدة البيانات.
- إنشاء تقييم، تحميل البنود من إصدار الأداة، autosave، save/resume.
- حساب MCM وSMCE مستقلان على الخادم مع سجل تدقيق.
- خريطة تدقيق كاملة لعناصر التحكم في `AUDIT.md`.

## الحالة والحدود الحالية

هذه دفعة الأساس الأولى وليست نظامًا جاهزًا للنشر العام. ما زالت الدعوات، RBAC الكامل، ملف الشركة، استيراد DOCX إلى قاعدة البيانات، التشخيص والتوصيات، roadmap، التقارير PDF، benchmarking، exports، الإشعارات، الإعدادات، والترجمة الثنائية بحاجة إلى تنفيذ كما هو مرتب في `AUDIT.md`.

قبل الإنتاج: انقل SQLite إلى PostgreSQL، استبدل حساب التطوير بمزود هوية مُدار، أضف CSRF/rate limiting/secret management، وطبّق اختبارات API وترحيلات قاعدة البيانات.

## Vercel

تمت إضافة `vercel.json` و`api/index.py` كنقطة Function. لا تنشر نسخة الإنتاج قبل ضبط اتصال PostgreSQL خارجي ومتغيرات الهوية، لأن نظام ملفات Vercel لا يحافظ على `mcm.sqlite3`. بعد تثبيت Vercel CLI وتسجيل الدخول:

```bash
npm install --global vercel
vercel login
vercel --prod
```
